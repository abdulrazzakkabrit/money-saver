What you get

  • English, Arabic and Czech
  • Light and dark mode

How to install

On iPhone or iPad

  1. Open this page in Safari.
  2. Tap the Share button, then Add to Home Screen.

On Android (Chrome or Samsung Internet)

  1. Open this page in the browser.
  2. Tap the menu (⋮), then Install app or Add to Home screen.

On a computer (Chrome or Edge)

  1. Open this page.
  2. Click the install icon in the address bar, or the menu, then Install Money Saver.
